These are graphics that you can use when creating ELDEN RING Reforged media, such as videos and reviews.
You can also use them to make shortcuts, Steam decorations etc. for yourself.

Do not use these graphics for anything unrelated to ELDEN RING Reforged.

Try to use the transparent Rune graphics exclusively with a dark background. You can add faded dark gradients behind the logo, should it be on top of an otherwise bright thumbnail.
