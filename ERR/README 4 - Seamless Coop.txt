===================================================================
ELDEN RING Reforged Compatibility: Seamless Coop by LukeYui
===================================================================
Seamless Coop is a popular mod by LukeYui which allows multiplayer cooperation in mods.
ELDEN RING Reforged adds many fixes for Seamless Coop issues, and many mechanics that integrate with cooperative play.

Here's a basic guideline on how to set it up with Reforged.

1) Download version the latest version of Seamless Coop from Nexus: https://www.nexusmods.com/eldenring/mods/510

2) Open the Seamless Coop archive you just downloaded, and enter the "SeamlessCoop" folder inside.

3) From this folder, drag ONLY the following into Reforged's "dll\offline" folder:

    - ersc.dll
    - locale

3) Add your desired password to the existing "dll\offline\ersc_settings.ini" file in the Reforged folder.

4) Run ERR via the "Offline (Windows)" or "Offline (Linux)" launcher shortcut, depending on your operating system.
Reforged should now be launching properly with Seamless Coop. If not, please check the previous steps again.

!!! AGAIN: !!!

Use the OFFLINE launcher! Seamless Coop is its own type of "online", but Online Mode refers to
Reforged's own included multiplayer capabilities. Seamless Coop needs to be run in Reforged's Offline Mode.

!!!!!!!!!!!!!!

Known issues:
- Seamless Coop is generally a fairly buggy experience; most bugs can be attributed to Seamless itself.
- The Codex of the All-Knowing functions very unreliably in coop, especially when it comes to
  giving all players the same progress.
